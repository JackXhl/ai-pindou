# 图纸库样例画廊与卡片视觉设计

- 日期：2026-08-15
- 状态：待实现
- 范围：`/patterns/` 画廊 UX、样例卡片视觉、约 48 个原创静态样例

## 背景与目标

对照 [pindou.fun](https://pindou.fun/) 的社区画廊观感：大图卡片、可刷的列表。爱拼豆保持纯静态、无账号，因此**只学布局与卡片视觉，不搬对方样例与 IP 角色**。

成功标准：

1. 图纸库可按分类筛选，默认瀑布流无限滚动，可切换分页。
2. 卡片预览接近正方形大图，信息层级清晰，「同款」一键进编辑器。
3. 样例约 48 个，原创像素题材，覆盖入门/可爱/风景/静物/人像感/节日/几何等。
4. 首页仍只展示少量 `featured` 精选，不改成完整社区画廊。

## 非目标

- 不爬取、不镜像 pindou.fun 或其它站点的图纸数据。
- 不展示热门动漫/动画/国创/小说等未授权 IP 角色（换姿势/画风亦不纳入本方案）。
- 不做点赞、收藏、登录、用户投稿（文案可保留「筹备中」）。
- 第一期不引入公有领域照片批量转图纸（可作为后续试点）。

## 决策摘要

| 项 | 选择 |
| --- | --- |
| 样例来源 | A1 原创像素题材 |
| 数量 | M ≈ 48 |
| 浏览 | B：默认瀑布流 + 可切分页 |
| 落点 | G1：完整画廊在 `/patterns/`；首页精选横滑 |
| 实现路径 | 扩展 `generate-samples.ts` → 静态 JSON 入库 |

## 卡片视觉

对齐社区站观感，收敛为爱拼豆组件：

- 大预览区：接近正方形；canvas 居中绘制完整图案；浅底；大圆角。
- 标题 + 色数角标；一行副信息：`宽×高 · 颗数 · 分类`。
- 主操作文案「同款」（链到 `/editor/?sample=<id>`）；整卡可点。
- 桌面悬停轻微上浮/阴影；移动端无悬停依赖。
- 不显示作者/点赞（无账号体系）。

首页精选卡可沿用同一卡片组件的紧凑或标准模式，避免两套视觉。

## 图纸库交互（`/patterns/`）

- 顶栏分类 chip：全部 + 入门 / 可爱 / 风景 / 静物 / 人像感 / 节日 / 几何（与样例 `tag` 对齐）。
- 右上切换：**瀑布流 | 分页**（默认瀑布流；偏好可写入 `localStorage`，键名带 `aipindou` 前缀）。
- 瀑布流：多列栅格；接近底部用 `IntersectionObserver` 再加载下一批（每批 12）。
- 分页：每页 24，底部分页器。
- 列表数据来自 `public/samples/index.json`；单卡详情/网格按需 `fetch` 各 `samples/<id>.json` 画预览。
- SEO：页面壳与文案保持 Astro 静态输出；样例网格以客户端岛为主（与现状一致）。首屏可优先渲染前若干 featured/前 12 条元信息（实现时按成本取舍，不阻塞主路径）。

## 样例分类与规模

| 分类（tag） | 约数量 | 方向 |
| --- | --- | --- |
| 入门 | 8 | 爱心、笑脸、星、简单符号 |
| 可爱 | 10 | 小动物剪影、水果、甜品 |
| 风景 | 8 | 日出、山丘、海浪、星空等低色块风景 |
| 静物 | 6 | 花瓶、茶杯、书本、植物 |
| 人像感 | 6 | 抽象脸型/半身剪影（非真人、非明星） |
| 节日 | 6 | 灯笼、雪花、礼物等 |
| 几何 | 4 | 渐变、马赛克、色块构成 |

- 保留并纳入现有 8 个样例；其余由脚本新生成。
- `featured: true` 约 8～12 个供首页。
- 尺寸：多数 `29×29`；少数 `52×52` 或 `58×29` 展示进阶密度。
- 色卡：默认 MARD 221 + 2.6mm，走现有 `generate()`。

## 生成管线

1. 扩展 `scripts/generate-samples.ts`：每个样例一个 `paint()` 像素绘制函数。
2. 输出 `apps/web/public/samples/<id>.json` 与更新 `index.json`。
3. 元数据字段：沿用 `SampleMeta`；`tag` 即分类 chip；如需可增加 `category` 与 `tag` 同值以兼容旧数据（实现时二选一，避免双源真相——**以 `tag` 为唯一分类字段**）。
4. 命令：`pnpm generate:samples`；生成物提交入库。`pnpm check` 不强制每次重跑生成。

## 组件与数据流

```
index.json
  → listSamples()
SampleGallery.vue（图纸库）
  ├─ 分类 chip + 瀑布流/分页切换
  ├─ IntersectionObserver / 分页器
  └─ SamplePatternCard.vue（大预览）
       → /editor/?sample=id
            → loadSample → applySampleToEditor
```

改动面：

- `SamplePatternCard.vue`：大图视觉。
- 新增 `SampleGallery.vue`（或显著扩展 `SamplePatternGrid.vue`）：筛选 + 双模式加载；首页精选继续用 Grid/Gallery 的 featured 模式。
- `patterns/index.astro`：挂载 Gallery。
- `samples.ts`：筛选辅助；预览 canvas 提高分辨率。
- `generate-samples.ts`：扩至约 48 个画家函数。

错误处理：列表失败可重试；单卡预览失败显示占位，不拖垮整页。

## 版权说明（产品约束）

热门动漫、动画、国创、小说等 IP 角色形象受著作权保护。公开画廊提供可识别角色的图纸（含「同款」打开/导出）通常需要授权；换画风或姿势一般不能免除风险。本方案明确采用原创题材，避免开源仓与线上展示的侵权暴露面。
